# Stack & Queue Student Records

## Overview
Two C++ programs that store student records and implement custom stack and queue behavior using `std::vector` as the underlying container.

## Stack operations
- Push
- Pop
- Top
- Size
- Empty check

## Queue operations
- Enqueue
- Dequeue
- Front
- Last
- Size
- Empty check

## Student record
Each record stores a student name, student number, and grade.

## Build
```bash
g++ -std=c++17 src/stack.cpp -o stack_demo
g++ -std=c++17 src/queue.cpp -o queue_demo
```
