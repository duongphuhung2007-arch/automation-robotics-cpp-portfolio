# Vector Management App

## Overview
An interactive C++ console application for practicing dynamic `std::vector` operations.

## Features
- Add an element to the end of a vector
- Remove the last element
- Insert an element at a specified position
- Remove a specified element
- Display the updated vector after each operation

## Build and run
```bash
g++ -std=c++17 src/main.cpp -o vector_app
./vector_app
```

## Skills demonstrated
C++, STL vectors, functions, loops, menu-driven programs, indexing, insertion/removal, and input validation.
